**3. Feedback storage, learning and live consumption**

- **No hourly overwrite found.** Each report inserts an autogenerated ID and exact millisecond timestamp. Recent UI shows five records. Any wet sighting wins over dry in that slot; a dry-only sighting sets the entire slot’s accumulation to zero.
