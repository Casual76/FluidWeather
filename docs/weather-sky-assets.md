# Sky cloud atlas

Generated with the built-in imagegen tool for this prototype, 2026-11-08.
Asset: `core-ui/src/main/res/drawable-nodpi/cloud_atlas_v1.png`.
1536×1024 RGBA, six cells in three columns/two rows; alpha range0–254.
The atlas is shared by the app and static widget renderer, decoded once per owner;
it supplies cloud structure only. Sky, light/tint, coverage, depth and movement stay
programmatic. No real-location image or meteorological observation is represented.
